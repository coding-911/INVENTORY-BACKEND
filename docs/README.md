## API 행 본문 (직접 내보내기 필요)

API 151개 각각의 요청·응답·오류·"하고 나면 바뀌는 것"은 노션 **API 목록** 데이터베이스의 행 페이지에 있다. `api-list.md`에는 색인과 링크만 있다.

- Claude Code에 Notion 연결(MCP)이 있으면 `api-list.md`의 링크로 직접 읽는다.
- 없으면 노션에서 내보내 `api/rows/`에 넣는다: API 명세서 페이지 → API 목록 데이터베이스 열기 → ⋯ → 내보내기 → 형식 "Markdown & CSV", "하위 페이지 포함" → 받은 zip을 풀어 `api/rows/`에 넣는다.

## 다시 내보낼 때

결정이 바뀌어 노션을 고치면, 바뀐 문서만 다시 내보내고 이 파일의 날짜를 고친다. 개발이 시작된 뒤 DB 구조의 원본은 저장소의 Flyway 마이그레이션이다(`db/ddl/`은 첫 마이그레이션의 출처로만 남는다).
